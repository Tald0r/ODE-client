# packetwire membership (docs/reviews/RESTRUCTURING.md tasks 1.1 and 2.4) - the
# wire layer: streams, sockets, encrypter, info classes, every packet
# class in every direction, and the factory/validator tables.
#
# Read by three consumers that must never disagree about what "the
# library" is: CMakeLists.txt (the packetwire target's source list),
# tests/arch/check_includes.pl (rules W0-W2) and tests/ratchet/ratchets.sh
# (R4). One repository-relative path per line; '#' starts a comment.
#
# Every .cpp under Client/Packet is either listed here or in
# tests/arch/packetwire_holdouts.txt; rule W0 fails on a file in neither.
# Extend deliberately: a file that cannot pass W1/W2 belongs in the
# executable, not here.

# writes the profile directory and reads the UI (task 5.1). The
# outbound half - RequestClientPlayer and its manager, this client
# dialling peers - was compiled out upstream and is deleted (task 5.2,
# eighth slice)
